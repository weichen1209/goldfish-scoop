# 夜市撈金魚

用紙網撈金魚的網頁小遊戲。紙泡水會變弱，魚越大越重，三支紙網都破了就結算。

- 網站：https://weichen1209.github.io/goldfish-scoop/
- 規格書：[SPEC.md](SPEC.md)

## 玩法

1. 按住滑鼠（或手指、空白鍵），紙網下水。泡越久紙越弱。
2. 等魚游到網子上，網框會變黃。
3. 放開起網。魚太重、紙太弱就會破。

按一下就放開是快撈；按住不放可以把網子留在水裡埋伏。小紅金魚和紅白金魚會結伴，一網撈到兩條以上有加成。黃金魚一下水就逃，只能先把網子放在牠前面等。
